# งานถัดไปของ Editor

## รักษาตำแหน่งและสัดส่วนลาย AI เมื่อปรับขนาดแพ็กเกจ

- [x] ทำให้เลเยอร์ที่ Copilot สร้างใหม่บนกล่องฝาเสียบตามแผงเดิมเมื่อปรับ W, D หรือ H และรักษาสัดส่วนโลโก้
- [x] ทดสอบใน Editor ว่าการลากปรับความลึกจาก 30 เป็น 85 มม. ใช้ Undo ครั้งเดียวและตำแหน่งลายตรงกันใน 2D, พื้นผิว 3D, SVG และ PDF
- [x] ให้ลายบนฉลากขวดหกเหลี่ยมอิงด้านหน้าแบนเมื่อตัวขวดหรือฉลากเปลี่ยนขนาด และคืนขนาดกับลายใน Undo เดียว
- [x] ให้ลายซองอิงพื้นที่ลำตัวด้านหน้าและหลังเมื่อปรับขนาดซอง ลายที่พาดหลายด้านอิงพื้นที่พิมพ์ของแผ่นฟิล์ม
- [x] ให้เปิดพรีวิวจับคู่ลาย Copilot รุ่นเก่าจากแถบโมเดลหรือตกแต่ง เลือกเลเยอร์ที่ต้องการ แล้วจึงบันทึกจุดอ้างอิงตามแผง
- [ ] ตรวจรูตัดและขอบแผงที่ไม่เป็นสี่เหลี่ยมหลังคำนวณตำแหน่งใหม่ และทดลองจัดบรรทัดเมื่อแผงแคบมาก

**ปัญหา** เมื่อ Copilot วางลายเสร็จ แล้วผู้ใช้ลากปรับกว้าง ลึก สูง หรือแก้ขนาดฉลาก โลโก้ ข้อความ และลายอาจเลื่อนผิดด้านหรือหลุดขอบ งานที่เห็นใน 2D, 3D และไฟล์ผลิตใช้ตำแหน่งเหล่านี้ร่วมกัน

**ที่มาจากโค้ดปัจจุบัน** [ตัวแปลงลาย AI](../src/core/aiArtwork.ts) รู้ว่าชิ้นงานอยู่แผงไหนตอนวางครั้งแรก แล้วบันทึกตำแหน่งเป็นมิลลิเมตรบนแผ่นคลี่ [Editor](../src/App.tsx) สร้างแผ่นคลี่ใหม่เมื่อขนาดเปลี่ยน ตำแหน่งเดิมจึงอาจไม่ตรงกับแผงที่ขยับแล้ว

**กรณีทำซ้ำ** ใช้ตัวสร้างกล่องฝาเสียบและตัววางลายจริง กำหนดกว้าง 80 มม. สูง 120 มม. แล้วเปลี่ยนความลึกจาก 30 เป็น 85 มม. มุมแผงหน้าขยับ 55 มม. ตามแนวนอนและ 60 มม. ตามแนวตั้ง แต่ชิ้นลายยังอยู่พิกัดเดิมและหลุดจากแผง

**แนวทางเสนอ**

1. เริ่มจากการปรับขนาดในเทมเพลตเดิม เก็บรหัสแผงและตำแหน่งอ้างอิงภายในแผงของเลเยอร์ AI จากตำแหน่งหลังจัดวางจริง เช่น กึ่งกลางด้านหน้าที่ความสูง 20% เมื่อเปลี่ยนขนาด ให้คำนวณจากตำแหน่งอ้างอิงเดิมทุกครั้ง และอัปเดตจุดอ้างอิงเมื่อผู้ใช้ย้ายเลเยอร์เอง
2. รักษาสัดส่วนโลโก้ ภาพ และตัวอักษร ให้สีพื้นและลายที่ออกแบบให้ชนขอบขยายตามแผงได้ ส่วนภาพพื้นหลังให้ครอปตามกรอบใหม่โดยรักษาสัดส่วนเดิม เมื่อพื้นที่แคบลงให้ตรวจขอบปลอดภัย จัดบรรทัดใหม่เมื่อจำเป็น และแจ้งผู้ใช้ถ้าข้อความเล็กเกินหรือเลเยอร์ยังล้น
3. ใช้ตำแหน่งที่คำนวณได้ชุดเดียวกันในพรีวิว 2D, 3D และไฟล์ผลิต เมื่อปล่อยเมาส์ให้บันทึกขนาดและตำแหน่งลายเป็นการแก้ไขครั้งเดียวเพื่อให้ Undo ย้อนทั้งคู่ได้ ตรวจขนาดและแผงอีกครั้งก่อนนำผลจาก AI หรือเวที 3D มาวาง หากโครงสร้างแผงเปลี่ยนให้แสดงพรีวิวก่อนยืนยัน
4. บันทึกข้อมูลอ้างอิงแบบไม่บังคับในไฟล์งานและ Cloud สำหรับงานเก่าที่ไม่มีข้อมูลนี้ ให้ทดลองจับคู่ในพรีวิวเฉพาะชิ้นที่อยู่ในแผงเดียวได้ชัดเจน หากเปลี่ยนเทมเพลต แผงหาย หรือลายพาดหลายแผง ให้ผู้ใช้ตรวจผลก่อนย้ายลาย

**เกณฑ์รับงานรอบแรก**

- ยืดเฉพาะความกว้างแล้วโลโก้ยังอยู่กึ่งกลางด้านเดิมและไม่ยืดตามแกนเดียว ข้อความไม่ข้ามรอยพับ
- ลากย่อและขยายกลับหลายครั้งแล้วตำแหน่งไม่คลาดสะสม Undo หนึ่งครั้งคืนทั้งขนาดและลาย
- บันทึกและเปิดงานใหม่แล้วตำแหน่งลายตรงกันใน 2D, 3D และไฟล์ SVG/PDF
- งานเก่า เลเยอร์ที่วางเอง และกรณีจับคู่แผงไม่ได้เปิดได้ครบและมีทางให้ตรวจตำแหน่งก่อนย้าย

ทดสอบ Editor V2 ในเครื่องด้วยผลจาก Copilot จำลอง ฉลากขวดหกเหลี่ยมลดความสูงจาก 80 เป็น 45 มม. แล้ว Undo ได้ในครั้งเดียว โลโก้ยังอยู่บนด้านหน้าแบนและคงสัดส่วน 2:1 ส่วนซองทดสอบการปรับขนาดด้วยถุงตั้ง และทดสอบตำแหน่งครึ่งแผงหลังของซองหลังกลางในเทสต์เรขาคณิต

สำหรับงานเก่า ปุ่ม **พรีวิวจับคู่ลาย AI กับแผง** จะขึ้นในงานกล่องฝาเสียบ ฉลากขวดหกเหลี่ยม หรือซองที่มีเลเยอร์จาก Copilot ที่ยังไม่มีจุดอ้างอิง พรีวิวแสดงลายเดิมกับขอบแผง ให้ยืนยันเป็นรายเลเยอร์ ระบบบันทึกจุดอ้างอิงเมื่อยืนยัน ตำแหน่งจะคำนวณตามแผงเมื่อปรับขนาดครั้งถัดไป

ทดสอบผ่าน Editor V2 ในเครื่องด้วยไฟล์ตัวอย่างที่สร้างจาก PackIt รุ่น `7f07f74` ก่อนเก็บจุดอ้างอิง กล่องฝาเสียบปรับความลึก 30 → 85 มม. ฉลากขวดหกเหลี่ยมปรับความสูง 80 → 45 มม. และซองตั้งปรับความกว้าง 100 → 145 มม. โลโก้คงสัดส่วน 2:1 ลายอยู่ในแผงที่ยืนยัน และ Undo ครั้งเดียวคืนขนาดกับพิกัดเดิมครบ ตรวจตำแหน่งบนแผ่นคลี่และในไฟล์สำรอง แล้วเปิดงานใหม่เพื่อยืนยันว่าจุดอ้างอิงยังอยู่
